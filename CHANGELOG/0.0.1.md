# VneuroTK 0.0.1

Initial alpha release of VneuroTK, a Python toolkit for combining neural recordings with visual-model representations.

## Highlights

- Continuous, epoched, and row-level neural data containers with validated trial and stimulus alignment.
- Lazy MNE, electrophysiology, and HDF5 loading with explicit data-integrity checks.
- Versioned HDF5 schema with legacy compatibility fixtures, typed stimulus IDs, atomic saves, and extraction provenance.
- Vision extraction through Transformers, timm, and ThingsVision backends with configurable layer selectors.
- Downloadable NOD-MEG and MonkeyVision sample datasets with SHA-256 verification and safe, bounded extraction.
- Offline unit tests plus opt-in real-sample, backend, network, and integration test lanes.
- Python 3.11-3.14 core support, validated wheel/source distributions, and protected PyPI publishing.

## Stability

This is a pre-alpha release. Public APIs and the HDF5 schema may evolve before 1.0. Pin the package version and retain original research data when using VneuroTK in reproducible workflows.

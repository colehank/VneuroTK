# Changelog

Release notes are maintained in versioned source files to avoid two changelogs drifting apart.

## 0.0.1 — Initial alpha release

VneuroTK's first release introduced neural-data containers and trial alignment, lazy recording loaders, versioned HDF5 persistence, DNN vision extraction through multiple backends, verified NOD-MEG and MonkeyVision sample downloads, capability-gated tests, and Python 3.11–3.14 packaging.

Read the canonical [`CHANGELOG/0.0.1.md`](https://github.com/colehank/VneuroTK/blob/main/CHANGELOG/0.0.1.md) for the complete highlights and stability notice.

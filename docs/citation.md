# Citing VneuroTK

Use the repository's [`CITATION.cff`](https://github.com/colehank/VneuroTK/blob/main/CITATION.cff) metadata when citing the software. Cite the exact released version you installed, or the full Git commit for an unreleased source snapshot. The runtime version is available as `vneurotk.__version__`.

VneuroTK derives versions from Git tags and development revisions. Consequently, `CITATION.cff` does not carry a manually maintained version or release date that could become stale. The project does not currently claim a software DOI; do not invent one. A plain-text citation may use this structure:

> Guohao Zhang. *VneuroTK* (version or Git revision). https://github.com/colehank/VneuroTK

Software citation does not replace citations required by datasets, pretrained models, or other research artifacts. Record and cite those separately according to their authoritative source metadata and terms. See the [data policy](data-policy.md).

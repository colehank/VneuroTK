# Support

The canonical support policy is [`SUPPORT.md`](https://github.com/colehank/VneuroTK/blob/main/SUPPORT.md).

VneuroTK is volunteer-maintained pre-alpha software with no service-level agreement. Use GitHub issues for reproducible bugs and focused proposals, and private vulnerability reporting for security issues. Include Python and VneuroTK versions, the installed extra/backend, data source and license information, network/integration details, and a minimal reproduction without restricted material.

Read the [data policy](data-policy.md) before reporting problems involving recordings, stimuli, downloaded models, or sample datasets.
